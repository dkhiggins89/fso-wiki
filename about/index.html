About this wiki

This wiki is part of the game's source. Most pages are generated from the game itself: item stats, shop prices, drop chances, recipes, monster stats, skill unlocks, quests and maps are read from the same data and rules the game runs on, so they are always right for the version they were built from. The footer of every page names that world and its revision.

Written content lives beside it: guides, update posts, and notes added under any generated page.

Keeping it up to date

Every change to the game updates the wiki in the same piece of work:

  1. Add an update post in wiki/pages/updates/ describing what changed for players.
  2. Add or change guide pages and page notes where the change needs explaining.
  3. Rebuild with .venv/Scripts/python.exe tools/wiki/build_wiki.py and check the changed pages.

The full procedure is in docs/WIKI.md.
