Linux, Steam Deck and controllers

2026-10-19

Linux and Steam Deck

  • There is now a Linux version of the game for 64-bit Linux PCs and the Steam Deck. It comes as FSO-linux.tar.gz:

unpack it anywhere and run FSO.sh. It connects to the official server like the Windows game, and your character is the same one on both.

  • Steam Deck: in Desktop Mode, unpack the folder, then in Steam choose Add a Non-Steam Game, browse to FSO.sh and

add it. Start it from Steam (Game Mode, or the Steam library in Desktop Mode): then the controller works as below. Started by double-clicking in Desktop Mode, Steam's own desktop controls drive it instead (trackpad pointer, R2 click, L2 right click, Steam + X keyboard).

  • The server itself still runs on Windows only; this is the game you play.

Playing with a controller

Any game controller works, including the Steam Deck's own controls. The game is still played by pointing and clicking, so the right stick moves the mouse pointer:

ControlWhat it does
Left stick or d-padWalk
Right stickMove the pointer
A or RTClick (walk somewhere, use the thing under the pointer, press buttons)
X or LTOptions for the thing under the pointer (the right-click menu)
YTalk, pick up, open (E)
RBAttack, or use the tool you hold (Space)
LBGuard (Q)
BClose windows and menus, or stop walking
StartGame menu (Esc)
BackInventory (I)
L3World map (M)
R3Zoom in a step (from the closest view, back to the widest)

On the Steam Deck the touch pads can also move the pointer, as in other games. The Help window (F1) lists the controls.

For world builders: the icon row at the bottom now has a Map editor button when you may edit the world, so the editor opens without F10 (the Steam Deck's keyboard has no F keys).

Small screens

On screens 800 pixels tall or less, like the Steam Deck's, the interface starts at its largest size so text stays readable. It can be changed in Settings > Interface.
